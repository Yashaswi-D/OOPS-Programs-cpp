## About the Repository

This repository contains the programs and lab exercises completed as part of the **Object Oriented Programming (OOP)** course.

The programs are implemented primarily in **C++** and demonstrate fundamental programming concepts such as classes and objects, constructors, encapsulation, inheritance, functions, strings, arrays, and parameter passing.

The repository is organized with clean, modular C++ programs covering both foundational concepts and practical object-oriented applications.

---

## Concepts Covered

The programs in this repository cover the following concepts:

- Classes and Objects
- Encapsulation and Data Hiding
- Data Members and Member Functions
- Access Specifiers (`public`, `private`, `protected`)
- Scope Resolution Operator (`::`)
- Defining Member Functions Outside the Class
- Static Data Members and Static Member Functions
- Constructors and Destructors
  - Default Constructors
  - Parameterized Constructors
  - Constructor Execution Flow in Inheritance
- Functions and Parameter Passing
  - Functions with Arguments
  - Passing Objects as Arguments
  - Pass by Value vs Pass by Reference
- Inheritance Models
  - Single Inheritance
  - Multilevel & Multiple Inheritance
- Abstract Classes & Pure Virtual Functions
- String Handling (C-Style Character Arrays vs `std::string`)
- Arrays and Basic Problem Solving
- Real-World Modeling (Student Record Management, Banking Systems)
